# gemini-code
Example code that works on the UKMARS Gemini robot.

The linefollowing folder has multiple examples of working line follower code.

The mazesolving folder has an all-in-one file example of a mazesolver that can be deployed using Thonny and the pymazerunner sub folder has a micropython implementation that was heavily based on mazerunner-core. 

Any issues or bugs please log here on GitHub and we welcome PR's with improvements that will help current and future members
